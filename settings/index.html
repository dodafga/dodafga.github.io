逐步設定說明

約 5 分鐘
先講重點：你需要一個 Google 帳號，並在 Google Cloud Console 建立一個「OAuth 用戶端 ID（網頁應用程式）」。 這個 ID 是公開資訊（會出現在網頁原始碼裡），不是密碼，可以安全貼在網站上。

  1. 建立 Google Cloud 專案

    開啟 Google Cloud Console → 建立專案。

    專案名稱隨便取，例如 inspection-suite，按「建立」，等幾秒後在上方專案選擇器切換到剛建立的專案。

  2. 啟用 Google Drive API

    到 Drive API 頁面，按「啟用（Enable）」。

    沒有啟用這一步，之後存檔會出現 Drive API 403 錯誤。

  3. 設定 OAuth 同意畫面

    到 OAuth 同意畫面：

    User Type選「外部（External）」，按建立
    應用程式名稱填 營建查驗資料（或任何你認得的名稱）
    使用者支援電子郵件填你自己的 Gmail
    開發人員聯絡資訊填你自己的 Gmail
    範圍（Scopes）按「新增或移除範圍」，搜尋 drive.file 並勾選
    測試使用者把自己的 Gmail 加進去（未發布前只有測試使用者能授權）

    存檔後回到同意畫面總覽，狀態會是「測試中（Testing）」。這樣就夠用了，不需要送審發布。

  4. 建立 OAuth 用戶端 ID

    到 憑證頁面 → 「建立憑證」→「OAuth 用戶端 ID」。

    應用程式類型選「網頁應用程式（Web application）」
    名稱填 inspection-suite-web
    已授權的 JavaScript 來源填 https://dodafga.github.io
    已授權的重新導向 URI留空（本程式用 token 模式，不需要）

    按「建立」，會跳出一個視窗顯示 Client ID，複製它。

  5. 把 Client ID 貼回本頁

    回到上面「Google OAuth Client ID」區塊，貼上並按「儲存 Client ID」。

    然後按「🔗 連線 Google Drive」，會跳出 Google 授權視窗，選擇你的帳號並同意 drive.file 權限。

  6. 開始使用

    回到 查驗紀錄表 或 查驗單，按「☁ 存到 Google Drive」。

    第一次會自動在雲端硬碟建立 營建查驗資料 資料夾與 inspection-data.json；之後每次存檔都覆寫同一份。

常見問題
· 授權視窗沒跳出來：可能是瀏覽器封鎖彈出視窗，或廣告封鎖器擋住 accounts.google.com。
· 出現「存取遭拒 / access_denied」：你的 Gmail 沒有被加進「測試使用者」，回步驟 3 補上。
· 出現「origin 不符」：步驟 4 的「已授權的 JavaScript 來源」要完全等於 https://dodafga.github.io（不要加斜線、不要加路徑）。
· 本機測試：若用 http://localhost:8000 測試，要把該網址也加進「已授權的 JavaScript 來源」。
· 換裝置：Client ID 要重新貼一次；資料則按「⬇ 從 Google Drive 載入」即可取回。

權限與隱私

使用的 scope：https://www.googleapis.com/auth/drive.file
這個 scope 只能存取「本程式自己建立或使用者明確開啟」的檔案，看不到你雲端硬碟裡的其他任何檔案， 也不能讀取 Gmail、通訊錄或日曆。

資料流向：瀏覽器 → Google Drive API（HTTPS 直連）。沒有任何中間伺服器，資料不會經過本網站以外的第三方。

離線可用：所有資料同時存在瀏覽器 localStorage，未授權或斷網時仍可正常填寫與匯出 Excel； 恢復後再手動按「存到 Google Drive」同步即可。
